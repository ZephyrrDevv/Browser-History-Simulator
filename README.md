# Browser History Simulator

**Cluster 1 — Project 2 | Vyntrax Industry**

A vanilla JavaScript app that mimics how a browser tracks your navigation history using arrays. Visit URLs, go back through your history, and watch the list update in real time.

---

## Features

- Visit any valid URL and track it in a history list
- "Go Back" removes the last visited page using `pop()`
- Current page always highlights with a live badge
- URL validation — rejects empty inputs and invalid URLs
- Responsive layout with mobile support

## Concepts Used

`push()` · `pop()` · `array.length` · `innerHTML` · `textContent` · `for` loop · ternary operator · URL validation · DOM event listeners · `renderList` pattern

## How to Run

Just open `index.html` in your browser. No installs needed.
